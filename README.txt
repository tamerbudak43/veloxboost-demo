VELOX — Arbitraj Havuzlari Demo

Kurulum:
1. ZIP dosyasini acin.
2. Icindeki "app" ve "components" klasorlerini proje ana klasorune kopyalayin.
3. Windows sorarsa tum dosyalarda "Degistir" secin.
4. Terminalde calisan pnpm dev varsa Ctrl + C yapin; sonra yeniden pnpm dev yazin.
5. Tarayicida Ctrl + F5 yapin.

Havuz kurallari:
- Ilk 10 havuz: 10.000–30.000 USDT
- 11. havuzdan itibaren: 20.000–30.000 USDT
- Havuz esige ulasinca aktif olur ve sonradan yatirim almaz.
- 30.000'i asan tutar otomatik olarak sonraki bekleyen havuza aktarilir.

Test senaryosu:
- Bekleyen Havuz #7 baslangicta 18.000 USDT'dir.
- Oğuz / 8000 ile "Demo yatirimi ekle" tusuna basinca #7, 26.000 USDT ile aktiflesir.
